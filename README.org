* Overview

playlisp is a Common Lisp library for parsing, constructing, and editing
extended M3U playlist files using CLOS objects. It was written for dynamic
playlist support in the Asteroid Radio project.

The library has three layers:

- =playlisp/parser= -- parses M3U files and strings into =playlist= and =track=
  objects. The parser is built on [[https://github.com/fade/parsector][parsector]], a monadic parser combinator
  library, and supports arithmetic expressions in =EXTINF= duration fields
  (e.g. =(3*60)+45= for 225 seconds).
- =playlisp/m3u-operations= -- functions for querying and mutating =playlist=
  objects: finding tracks, removing tracks, and inserting tracks at arbitrary
  positions.
- =playlisp/src/app= -- a full-screen terminal TUI editor for M3U playlists,
  launched via =playlisp:run-tui=.

* Installation

Clone the repository and ensure it is visible to ASDF (e.g. via
=asdf:*central-registry*= or a source registry configuration):

#+begin_src lisp
(push (truename "path/to/playlisp/") asdf:*central-registry*)
(asdf:load-system :playlisp)
#+end_src

Loading =:playlisp= is sufficient; it brings in the parser, operations, and
TUI layers automatically.

* M3U Format

playlisp parses the extended M3U format. A playlist file looks like this:

#+begin_example
#EXTM3U
#PLAYLIST:Underworld & Friends
#PHASE:Underworld & Friends
#DURATION:6 hours (approx)
#CURATOR:Asteroid Radio
#DESCRIPTION:Underworld and adjacent electronic artists
#EXTINF:-1,Underworld - Born Slippy (Nuxx)
/app/music/Underworld/01 Born Slippy (Nuxx).flac
#EXTINF:(3*60)+45,Orbital - Halcyon
/app/music/Orbital/Halcyon.flac
#EXTINF:180,The Chemical Brothers - Block Rockin' Beats
/app/music/Chemical Brothers/Block Rockin Beats.mp3
#+end_example

The parser recognizes:

- =#EXTM3U= header (required)
- Metadata lines: =#KEY:value= -- keys are interned as keywords
- Track entries: =#EXTINF:duration,title= followed by a file path
- Duration expressions: integers, =-1= for indefinite/live, or arithmetic like =(3*60)+45=
- Comment lines (starting with =;=) and blank lines (silently skipped)
- Files with or without a trailing newline

The following metadata keys are mapped to playlist slots:

| Key           | Slot                 |
|---------------+----------------------|
| =#PLAYLIST:=    | =playlist-name=        |
| =#PHASE:=       | =playlist-phase=       |
| =#DURATION:=    | =playlist-duration=    |
| =#CURATOR:=     | =playlist-curator=     |
| =#DESCRIPTION:= | =playlist-description= |

* CLOS Classes

** =playlist=

Represents a parsed M3U playlist.

| Accessor             | Initarg               | Description                          |
|----------------------+-----------------------+--------------------------------------|
| =playlist-name=        | =:playlist-name=        | Name of the playlist (required)      |
| =playlist-phase=       | =:playlist-phase=       | Phase/mood segment name              |
| =playlist-duration=    | =:playlist-duration=    | Human-readable total duration string |
| =playlist-curator=     | =:playlist-curator=     | Who curated the playlist             |
| =playlist-description= | =:playlist-description= | Description of mood/tone             |
| =playlist-elements=    | =:playlist-elements=    | List of =track= instances              |

Constructor: =(make-playlist name &key phase duration curator description elements)=

The =curator= slot defaults to the value of the =USER= environment variable.

** =track=

Represents a single track in a playlist.

| Accessor   | Initarg     | Description                             |
|------------+-------------+-----------------------------------------|
| =title=      | =:title=      | Track title                             |
| =artist=     | =:artist=     | Artist name                             |
| =track-path= | =:track-path= | Path to the media file (required)       |
| =qnumber=    | =:qnumber=    | 1-based position within the playlist    |
| =runtime=    | =:runtime=    | Duration in seconds (=-1= for indefinite) |

Constructor: =(make-track title path &key artist runtime position)=

* Usage

** Parsing a playlist file

#+begin_src lisp
(defvar *playlist*
  (playlisp:parse-m3u-file #p"/path/to/playlist.m3u"))

(playlisp:playlist-name *playlist*)
;; => "Underworld & Friends"

(playlisp:playlist-curator *playlist*)
;; => "Asteroid Radio"

(length (playlisp:playlist-elements *playlist*))
;; => 45
#+end_src

File encoding is detected automatically. To parse a specific encoding
explicitly, pass =:encoding= to the underlying parser:

#+begin_src lisp
(playlisp/parser:parse-m3u-file #p"/path/to/latin-1.m3u" :encoding :latin-1)
#+end_src

** Parsing a string

#+begin_src lisp
(defvar *playlist*
  (playlisp:parse-m3u
    (format nil "#EXTM3U~%#PLAYLIST:My Mix~%#EXTINF:225,Artist - Song~%/music/song.mp3~%")))

(playlisp:playlist-name *playlist*)
;; => "My Mix"
#+end_src

** Accessing tracks

#+begin_src lisp
(let ((track (first (playlisp:playlist-elements *playlist*))))
  (playlisp:title track)       ;; => "Underworld - Born Slippy (Nuxx)"
  (playlisp:runtime track)     ;; => -1
  (playlisp:track-path track)  ;; => "/app/music/.../01 Born Slippy (Nuxx).flac"
  (playlisp:qnumber track))    ;; => 1
#+end_src

** Constructing playlists programmatically

#+begin_src lisp
(defvar *my-playlist*
  (playlisp:make-playlist "Late Night Session"
    :phase "Downtempo"
    :curator "fade"
    :description "Ambient and downtempo selections"
    :elements (list (playlisp:make-track "Boards of Canada - Dayvan Cowboy"
                                         "/music/boc/dayvan-cowboy.flac"
                                         :runtime 315)
                    (playlisp:make-track "Tycho - A Walk"
                                         "/music/tycho/a-walk.flac"
                                         :runtime 384))))
#+end_src

** Iterating over tracks

#+begin_src lisp
(dolist (track (playlisp:playlist-elements *playlist*))
  (format t "~3D. ~A (~A sec)~%"
          (playlisp:qnumber track)
          (playlisp:title track)
          (playlisp:runtime track)))
#+end_src

** Playlist operations (=playlisp/m3u-operations=)

The =playlisp/m3u-operations= package (nickname =m3uop=) provides functions
for querying and mutating playlist objects. All operations keep =qnumber=
slots consistent after modification.

*** Finding a track

=(find-track playlist key &key (by :title))=

Returns the first matching track, or =NIL= if not found. The =by= keyword
selects the field to search: =:title= and =:artist= use case-insensitive
string comparison; =:qnumber= uses =eql=.

#+begin_src lisp
;; Find by title (case-insensitive)
(m3uop:find-track *playlist* "born slippy" :by :title)
;; => #<TRACK "Underworld - Born Slippy (Nuxx)">

;; Find by 1-based queue position
(m3uop:find-track *playlist* 3 :by :qnumber)
;; => #<TRACK ...> (the third track)

;; Find by artist (only populated when tracks are built with make-track :artist)
(m3uop:find-track *my-playlist* "Tycho" :by :artist)
;; => #<TRACK "Tycho - A Walk">

;; Returns NIL when not found
(m3uop:find-track *playlist* "No Such Track" :by :title)
;; => NIL
#+end_src

*** Removing a track

=(rmtrack track playlist)=

Removes =track= from =playlist= by object identity and renumbers the
remaining tracks. Returns the modified playlist.

#+begin_src lisp
(let ((track (m3uop:find-track *playlist* "Orbital - Halcyon" :by :title)))
  (m3uop:rmtrack track *playlist*))
;; => *playlist* (now without that track, remaining tracks renumbered)
#+end_src

*** Inserting a track

=((setf add-playlist-element) new-track playlist position)=

Inserts =new-track= into =playlist= at the 1-based =position=. Use =1= to
prepend, =-1= to append, or any positive integer to insert before the
track currently at that position. Renumbers all tracks afterwards.

#+begin_src lisp
(let ((new-track (playlisp:make-track "Underworld - Rez"
                                      "/music/underworld/rez.flac"
                                      :runtime 411)))
  ;; Append to end
  (setf (m3uop:add-playlist-element *playlist* -1) new-track)

  ;; Prepend to front
  (setf (m3uop:add-playlist-element *playlist* 1) new-track)

  ;; Insert at position 4 (before whatever is currently fourth)
  (setf (m3uop:add-playlist-element *playlist* 4) new-track))
#+end_src

** TUI editor

playlisp includes a full-screen terminal editor for M3U playlists, launched
with =playlisp:run-tui=.

#+begin_src lisp
;; Open the TUI with an existing playlist
(playlisp:run-tui "/path/to/playlist.m3u")

;; Open the TUI with an empty playlist
(playlisp:run-tui)
#+end_src

From the command line:

#+begin_src shell
sbcl --non-interactive \
  --eval '(push (truename "path/to/playlisp/") asdf:*central-registry*)' \
  --eval '(asdf:load-system :playlisp)' \
  --eval '(playlisp:-main (list "/path/to/playlist.m3u"))'
#+end_src

*** Keybindings

| Key         | Action                          |
|-------------+---------------------------------|
| =j= / =↓=     | Move cursor down                |
| =k= / =↑=     | Move cursor up                  |
| =g=           | Go to top                       |
| =G=           | Go to bottom                    |
| =PgUp=        | Page up                         |
| =PgDn=        | Page down                       |
| =Tab=         | Switch between tracklist/details pane |
| =a=           | Add track after cursor          |
| =A=           | Add track before cursor         |
| =K=           | Move selected track up          |
| =J=           | Move selected track down        |
| =d= / =Del=   | Delete selected track           |
| =n=           | New empty playlist              |
| =b=           | Browse filesystem to add tracks |
| =o=           | Open an M3U file                |
| =w=           | Save / write playlist           |
| =e=           | Edit playlist metadata          |
| =?=           | Show keybindings help           |
| =q= / =Esc=   | Quit                            |
